Focus management
Focus ring: box-shadow: 0 0 0 2px rgba(59,130,246,.4)

Modal open → focus first interactive element inside.
Tab cycles within modal only.
Modal close → return focus to trigger element.

Never use outline: none without a visible alternative.
Semantic HTML rules
<header> top nav bar
<main> page content
<aside> sidebar, right panel
<nav> navigation lists
<article> research paper
<section> page sections

Never <div role="button"> when <button> exists.
Reduced motion: every animation/transition must be inside @media (prefers-reduced-motion: reduce). Set all durations to 0.01ms !important. This is already applied globally in the :root CSS above.

All interactions must be achievable by keyboard. Tab order must match visual order (left-to-right, top-to-bottom).

EndJump to last item in listLong lists
Focus trap rules (modals)
On modal open
Move focus to first focusable element inside modal (usually the title or first button)
While modal open
Tab cycles only within the modal — never reaches page behind backdrop
On modal close
Return focus to the element that triggered the modal open
Backdrop click
Closes informational modals. Does NOT close destructive confirmation modals.
Escape key
Always closes modal (including destructive ones) — treat as cancel action
Screen reader announce
role="dialog" + aria-modal="true" + aria-labelledby pointing to modal title

21
Do / Don't
Non-negotiable. Violations create expensive inconsistency.
✓ Do
Use #3b82f6 as the primary action color
Use CSS variable tokens for every color value
Use DM Sans for all UI text (400 and 500 only)
Use 0.5px borders on all components
Use radius-lg (11px) for task cards
Add aria-label to every icon-only button
Add role="dialog" aria-modal to modals
Wrap all animations in prefers-reduced-motion
Use 16px font-size on mobile inputs
Use 44px min-height on mobile buttons/inputs
Load fonts via next/font/google with display:swap
Show credibility as bar + percentage + label
Map 422 errors to form fields (not toasts)
Use violet (#7c3aed) only for paid upgrade CTAs
Return focus to trigger after closing modal
✗ Don't
Never use #1E3A8A as a UI action color
Never hardcode hex values in components
Never use Inter, Roboto, Arial, or system-ui
Never use font-weight 600 or 700
Never use box-shadow in dark mode
Never put the right panel in the shell layout
Never use 3-col grid below 1280px
Never show a toast for 422 validation errors
Never use border-radius above 14px
Never stack two primary buttons together
Never use <div role="button"> when <button> exists
Never animate mode switch — instant swap only
Never load fonts via <link> tag (use next/font)
Never show credibility as stars only
Never use violet for non-upgrade actions
